# 从 0 搭建个人博客的第一份学习笔记

这篇文章用于记录 `life-notes` 的早期技术决策。

## 技术选择

当前项目选择：

- Next.js：用于页面路由和全栈能力。
- TypeScript：用于提升代码可靠性。
- Tailwind CSS：用于快速建立极简浅绿色视觉系统。
- MDX：用于以文件方式管理博客内容。

## 为什么先用文件驱动

第一阶段的目标是快速启动和持续学习。使用 `content/posts/*.mdx` 管理文章，可以让每一次内容更新都被 GitHub 清晰记录。

当后续需要评论、阅读量、后台发布等能力时，再接入数据库会更合理。
