# GitHub Pages Landing Page

此目录用于发布 Life Notes 的静态主页面。

- 页面入口：`github-pages/index.html`
- 部署方式：GitHub Actions 工作流 `.github/workflows/pages.yml`
- 触发方式：推送到 `main` 分支且修改 `github-pages/**` 或手动触发 workflow

部署完成后，页面通常可通过以下地址访问：

```text
https://zhoujie2001.github.io/life-notes/
```

如首次启用 GitHub Pages，需要在仓库 Settings → Pages 中将 Source 设置为 GitHub Actions。
